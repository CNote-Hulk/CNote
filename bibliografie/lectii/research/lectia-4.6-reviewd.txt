CONCEPT 1: Arhitectura Von Neumann – modelul fundamental al sistemului
INFORMAȚIE VERIFICATĂ:
- Modelul Von Neumann (1945, First Draft of a Report on the EDVAC) definește 5 componente: unitate aritmetică (ALU), unitate de control, memorie (shared date+instrucțiuni), stocare externă, I/O
- Stored-program: instrucțiunile și datele rezidă în aceeași memorie → flexibilitate software
- Von Neumann Bottleneck: bus-ul comun instrucțiuni/date limitează throughput-ul; severitatea crește cu fiecare generație CPU (viteza CPU crește mai repede decât bandwidth-ul memoriei)
- Descris de John Backus (1977 Turing Award): trafic masiv de cuvinte prin „bottleneck"
- Mitigări moderne: cache hierarchy (L1/L2/L3), cache-uri separate instrucțiuni/date (Modified Harvard), branch predictor, SoC (reduce distanța fizică), DMA, NUMA
- Calculatoarele moderne sunt de fapt Modified Harvard (cache-uri separate) dar cu memorie principală unificată Von Neumann
- Primul calculator stored-program funcțional: Manchester Baby (21 iunie 1948)
- Alternativa: Harvard Architecture – bus-uri complet separate instrucțiuni/date (folosită în microcontrolere)
SURSE: Wikipedia – Von Neumann Architecture (https://en.wikipedia.org/wiki/Von_Neumann_architecture)

CONCEPT 2: Componentele sistemului și ierarhia lor de performanță
INFORMAȚIE VERIFICATĂ:
- Ierarhia de viteză (de la cel mai rapid la cel mai lent):
  1. Registre CPU: <1ns, ~KB
  2. Cache L1: ~1ns, 32-64KB per core
  3. Cache L2: ~3-10ns, 256KB-1MB per core
  4. Cache L3: ~10-30ns, 4-64MB shared
  5. RAM DDR5: ~50-100ns, 8-128GB, bandwidth ~50-100 GB/s
  6. SSD NVMe: ~0.05-0.1ms (50-100μs), 250GB-8TB, sequential 3.5-14.8 GB/s
  7. SSD SATA: ~0.5-0.6ms, 120GB-4TB, sequential ~550 MB/s
  8. HDD: ~2.9-12ms, 500GB-36TB, sequential ~200 MB/s
- Fiecare nivel: capacitate mai mare, latență mai mare, cost/GB mai mic
- CPU (ISA + microarhitectură): IPC vechi ~0.1, modern ~1, superscalar 3-5 IPC; clock rate nu e metric suficient
- GPU: procesare paralelă masivă (mii de core-uri), optimizat throughput nu latency
- Performanță: latency (timp individual) vs throughput (lucru/timp), pipeline: crește throughput dar crește latency
- Eficiență energetică modernă: focusul s-a mutat de la clock speed la perf/watt (ex: Intel Haswell 30-40W→10-20W, reducere 50%)
SURSE: Wikipedia – Computer Architecture (https://en.wikipedia.org/wiki/Computer_architecture), lecțiile 4.1-4.5 anterioare
STATUS: VERIFICAT ✓

CONCEPT 3: Motherboard-ul ca platformă de integrare
INFORMAȚIE VERIFICATĂ:
- Motherboard = PCB principal care permite comunicarea între toate componentele (CPU, memorie, periferice)
- Componente pe motherboard modern: CPU socket, DIMM slots (DDR3/4/5), chipset, flash BIOS/UEFI, clock generator, expansion slots (PCIe), power connectors, storage connectors (SATA, M.2 NVMe), I/O (USB, Ethernet, audio, display)
- Perifericele integrate (onboard): disk controller, GPU integrat, sound card 7.1, Ethernet, USB, Wi-Fi, Bluetooth, senzori temperatură/tensiune/ventilatoare, PMIC
- Form factor: ATX (standard desktop), microATX, mini-ITX, EATX; laptopuri folosesc design miniaturizat integrat
- Bootstrapping: la pornire BIOS/UEFI execută POST (Power-On Self Test) → testează hardware (video, RAM, storage, USB, network) → detectează boot device → încarcă OS
- UEFI a înlocuit BIOS clasic (obligatoriu din Windows 8)
- Termenul „motherboard" din 1965; primul motherboard: Planar Breadboard (IBM PC, 1981, designat de Patty McHugh)
- Evoluția integrării: 1980s Super I/O (keyboard/mouse/serial) → late 1990s audio/video/network onboard → 2000s+ practice totul integrat
SURSE: Wikipedia – Motherboard (https://en.wikipedia.org/wiki/Motherboard)
STATUS: VERIFICAT ✓

CONCEPT 4: Chipset – evoluția de la Northbridge/Southbridge la PCH/SoC
INFORMAȚIE VERIFICATĂ:
- Chipset = set de circuite integrate pe motherboard care gestionează fluxul de date CPU↔memorie↔periferice
- Arhitectura clasică (pre-2003):
  - Northbridge: CPU ↔ RAM + GPU (high-speed), conectat la CPU prin Front-Side Bus (FSB)
  - Southbridge: periferice de viteză mică (USB, SATA, audio, PCI)
  - Northbridge intermediar între CPU și Southbridge
  - Performanța CPU foarte dependentă de Northbridge (memory performance)
- Evoluția către integrare:
  - 2003: AMD Athlon 64 – primul CPU cu memory controller integrat → elimină nevoia Northbridge pentru RAM
  - 2008: Intel Core i + X58 – Intel integrează memory controller
  - Progresiv: PCIe controller și GPU integrat pe CPU die
  - Intel Platform Controller Hub (PCH) = northbridge+southbridge condensate într-un chip (practic southbridge îmbunătățit, deoarece funcțiile northbridge sunt acum în CPU)
  - AMD Fusion Controller Hub (FCH) – echivalent AMD
  - Intel Skylake mobile: PCH integrat în package-ul procesorului (al doilea die)
  - AMD Zen: chipset-ul gestionează doar I/O lent (USB, SATA); toate conexiunile PCIe direct la CPU
  - AMD EPYC (server): SoC complet, fără chipset extern
- Interfețe moderne CPU↔chipset: DMI (Intel), UMI (AMD)
- Console/smartphone-uri: SoC (System on Chip) – CPU+GPU+memorie controller+I/O pe un singur die (Qualcomm Snapdragon, Apple A-series, AMD APU în console)
- Primul chipset PC: NEAT chipset (Chips and Technologies, 1984) pentru Intel 80286
SURSE: Wikipedia – Chipset (https://en.wikipedia.org/wiki/Chipset)
STATUS: VERIFICAT ✓

CONCEPT 5: Sinteza ierarhiei complete – cum funcționează sistemul ca un tot unitar
INFORMAȚIE VERIFICATĂ:
- Fluxul de date într-un sistem modern:
  CPU → (cache L1→L2→L3, pe die) → RAM (DDR, prin memory controller integrat în CPU) → Storage (SSD NVMe prin PCIe direct la CPU, sau SATA prin PCH/chipset) → Periferice I/O (USB/Ethernet/audio prin PCH/chipset)
- GPU: conectat prin PCIe x16 direct la CPU (lane-uri de la CPU, nu de la chipset); în APU/SoC – GPU pe același die cu CPU, partajează memoria RAM
- Principiul ierarhiei: fiecare nivel de stocare compensează bottleneck-ul nivelului anterior
  - Registre compensează latența cache-ului
  - Cache compensează latența RAM-ului (Von Neumann bottleneck mitigation)
  - RAM compensează latența storage-ului
  - SSD NVMe compensează latența HDD-ului
- Bus-urile conectează nivelurile: PCIe (high-speed: GPU, NVMe), SATA (storage legacy), USB (periferice), DMI/UMI (CPU↔chipset)
- DMA (Direct Memory Access): permite perifericelor să transfere date direct în/din RAM fără intervenția CPU
- Tendința modernă: maximizarea integrării pe un singur chip (SoC) pentru reducere latență, consum, cost
- Console moderne (PS5, Xbox Series X): APU custom AMD cu CPU Zen + GPU RDNA + memory controller pe un singur die, conectat la GDDR6 unificat
- PC modern: CPU (cu memory controller + PCIe controller + opțional GPU integrat) ↔ PCH (USB/SATA/audio/Ethernet/Wi-Fi) prin DMI; GPU discret pe PCIe x16; RAM pe DIMM-uri DDR5; NVMe SSD pe M.2 (PCIe direct la CPU sau la PCH)
