LECȚIA 3.2 – Porți logice
Cercetare verificată și curățată

========================================
CONCEPT 1: AND (ȘI)
========================================
INFORMAȚIE VERIFICATĂ:
- Poartă logică AND: ieșire = 1 doar dacă TOATE intrările sunt 1
- Echivalent matematic: A · B sau A ∧ B
- Tabel de adevăr (2 intrări):
  * 0 AND 0 = 0
  * 0 AND 1 = 0
  * 1 AND 0 = 0
  * 1 AND 1 = 1
- Identic cu tabelul de înmulțire binară
- Implementare: tranzistoare MOSFET în serie (ambele trebuie activate)
- Utilizare: verificare condiții simultane, mascare biți, operații aritmetice

SURSE: Wikipedia – Logic gate (https://en.wikipedia.org/wiki/Logic_gate)
STATUS: VERIFICAT – Informații factuale despre poarta AND

========================================
CONCEPT 2: OR (SAU)
========================================
INFORMAȚIE VERIFICATĂ:
- Poartă logică OR: ieșire = 1 dacă cel puțin o intrare este 1
- Echivalent matematic: A + B sau A ∨ B
- Tabel de adevăr (2 intrări):
  * 0 OR 0 = 0
  * 0 OR 1 = 1
  * 1 OR 0 = 1
  * 1 OR 1 = 1
- Implementare: tranzistoare MOSFET în paralel (oricare activat conduce)
- Utilizare: selectare semnale, combinare condiții, logică de decizie

SURSE: Wikipedia – Logic gate (https://en.wikipedia.org/wiki/Logic_gate)
STATUS: VERIFICAT – Informații factuale despre poarta OR

========================================
CONCEPT 3: NOT (NU / Invertor)
========================================
INFORMAȚIE VERIFICATĂ:
- Poartă logică NOT: o singură intrare, ieșirea este complementul (inversul)
- Echivalent matematic: ¬A sau Ā
- Tabel de adevăr:
  * NOT 0 = 1
  * NOT 1 = 0
- În electronică se numește „inverter"
- Simbol: cercul (bubble) pe schemă indică negare logică
- Implementare CMOS: un PMOS + un NMOS complementare (cel mai simplu circuit CMOS)
- Utilizare: inversarea semnalelor, generare complement, construirea altor porți

SURSE: Wikipedia – Logic gate (https://en.wikipedia.org/wiki/Logic_gate)
STATUS: VERIFICAT – Informații factuale despre poarta NOT

========================================
CONCEPT 4: NAND (NU-ȘI)
========================================
INFORMAȚIE VERIFICATĂ:
- Poartă logică NAND: inversul funcției AND (NOT-AND)
- Ieșire = 0 doar dacă TOATE intrările sunt 1; altfel = 1
- Echivalent matematic: ¬(A · B) sau A↑B (Sheffer stroke, Henry M. Sheffer, 1913)
- Tabel de adevăr (2 intrări):
  * 0 NAND 0 = 1
  * 0 NAND 1 = 1
  * 1 NAND 0 = 1
  * 1 NAND 1 = 0
- POARTĂ UNIVERSALĂ: orice funcție logică poate fi construită doar din porți NAND
  * NOT(A) = NAND(A, A)
  * AND(A,B) = NOT(NAND(A,B)) = NAND(NAND(A,B), NAND(A,B))
  * OR(A,B) = NAND(NAND(A,A), NAND(B,B))
- Demonstrat de C.S. Peirce (1880-1881), publicat de Sheffer (1913)
- Legea De Morgan: ¬(A · B) = ¬A + ¬B → NAND = OR cu intrări negate
- Chipul 7400 (Texas Instruments): 4 porți NAND într-un singur circuit integrat
- Utilizare: construirea oricăror funcții logice, latch-uri NAND, memorie

SURSE: Wikipedia – Logic gate (https://en.wikipedia.org/wiki/Logic_gate)
STATUS: VERIFICAT – Informații factuale despre poarta NAND și proprietatea de universalitate

========================================
CONCEPT 5: NOR (NU-SAU)
========================================
INFORMAȚIE VERIFICATĂ:
- Poartă logică NOR: inversul funcției OR (NOT-OR)
- Ieșire = 1 doar dacă TOATE intrările sunt 0; altfel = 0
- Echivalent matematic: ¬(A + B) sau A↓B (Peirce's arrow)
- Tabel de adevăr (2 intrări):
  * 0 NOR 0 = 1
  * 0 NOR 1 = 0
  * 1 NOR 0 = 0
  * 1 NOR 1 = 0
- POARTĂ UNIVERSALĂ: orice funcție logică poate fi construită doar din porți NOR
  * NOT(A) = NOR(A, A)
  * OR(A,B) = NOT(NOR(A,B)) = NOR(NOR(A,B), NOR(A,B))
  * AND(A,B) = NOR(NOR(A,A), NOR(B,B))
- Legea De Morgan: ¬(A + B) = ¬A · ¬B → NOR = AND cu intrări negate
- Latch SR din 2 porți NOR: cel mai simplu circuit de stocare (memorie pe 1 bit)
- Logică secvențială: porțile NOR formează latch-uri → flip-flop-uri → registre → memorie
- Utilizare: construirea oricăror funcții logice, latch-uri SR, SRAM

SURSE: Wikipedia – Logic gate (https://en.wikipedia.org/wiki/Logic_gate)
STATUS: VERIFICAT – Informații factuale despre poarta NOR și proprietatea de universalitate
