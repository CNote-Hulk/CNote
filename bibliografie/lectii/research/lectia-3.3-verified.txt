LESSON: 3.3 – Flip-flop și registre

---

CONCEPT: Latch (memorie digitală asincronă)

VERIFIED INFORMATION:
Latch-ul este un circuit bistabil level-triggered (sensibil la nivel), transparent când enable=1. SR Latch (Set-Reset): construit din 2 porți NOR cross-coupled. S=1,R=0 → Set (Q=1); S=0,R=1 → Reset (Q=0); S=0,R=0 → Hold; S=1,R=1 → invalid. Ecuație: Q_next = S + R̄·Q (cu constrângerea S·R = 0). Gated D Latch: un singur input D + Enable; R = complement D automat. E=1: Q urmează D (transparent); E=0: Q menține starea (opac). Inventat 1918 de Eccles și Jordan (trigger circuit cu tuburi vidate).

---

CONCEPT: Flip-Flop (bistabil sincron)

VERIFIED INFORMATION:
Flip-flop-ul este un circuit bistabil edge-triggered (sensibil la front), stochează 1 bit. D Flip-Flop (cel mai utilizat): captează D la frontul activ al ceasului. Master-slave: 2 gated D latches în serie cu enable inversat. T Flip-Flop (Toggle): T=1 → toggle la clock; T=0 → hold. Q_next = T ⊕ Q. Divide frecvența la 2 (utilizat în contoare). JK Flip-Flop (universal): J=Set, K=Reset, J=K=1 → Toggle, J=K=0 → Hold. Q_next = J·Q̄ + K̄·Q. Parametri critici: setup time (stabilitate date ÎNAINTE de front), hold time (DUPĂ front), propagation delay (front ceas → schimbare ieșire). Metastabilitate: stare imprevizibilă când date și ceas se schimbă simultan; soluție: cascadare.

---

CONCEPT: Registre (grupuri de flip-flop-uri)

VERIFIED INFORMATION:
Registrul = grup sincronizat de flip-flop-uri ce stochează o colecție de biți (un cuvânt/word). Word size = numărul de flip-flop-uri = numărul de biți stocați. Memorie volatilă: pierde datele la pierderea alimentării. Semnale: Reset (inițializare), Clock (front activ → stocare), Data in, Data out. Load enable: multiplexor 2-to-1 selectează între data nouă și stare curentă → permite stocare selectivă.

---

CONCEPT: Aplicații ale registrelor

VERIFIED INFORMATION:
Shift register (registru de deplasare): transferă fiecare bit la flip-flop-ul adiacent la fiecare ciclu de ceas. Tipuri: SIPO (serial-in parallel-out), PISO (parallel-in serial-out). Contor binar sincron: logică incrementează valoarea stocată la fiecare ciclu. Register file: grup de registre adresabile. Scriere prin decoder + activare LD; citire prin multiplexor sau buffere tri-state. Registre CPU: date, adrese, stare, configurare. Registre periferice: acces prin memory-mapped I/O sau port-mapped I/O. Operații atomice pe biți: set/clear/complement fără read-modify-write (evită race conditions).
