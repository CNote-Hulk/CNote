LECȚIA 7.2 – CPU-BOUND vs GPU-BOUND
MATERIAL VERIFICAT ȘI SINTETIZAT
========================================

CONCEPT 1: CPU-bound – limitarea de procesor
INFORMAȚIE VERIFICATĂ:
- Un task este CPU-bound (compute-bound) când timpul de finalizare depinde principalment de viteza CPU-ului
- Utilizare procesor ridicată (poate 100% pentru perioade extinse)
- Exemple tipice: calcule matematice intensive, logica jocului, inteligență artificială, simulări fizice
- Poate beneficia de paralelizare (multithreading) dacă algoritmul permite
- Soluții: upgrade CPU, optimizarea codului, distribuirea sarcinii pe mai multe core-uri
- Opusul: I/O-bound (limitat de periferice), memory-bound (limitat de memorie)
SURSE: Wikipedia – CPU-bound (https://en.wikipedia.org/wiki/CPU-bound)
STATUS: VERIFICAT

CONCEPT 2: GPU-bound – limitarea de procesor grafic
INFORMAȚIE VERIFICATĂ:
- Un task este GPU-bound când performanța este limitată de capacitatea GPU-ului
- GPU-ul procesează grafică prin unități de calcul masiv paralele (sute sau mii)
- Structura SIMD (Single Instruction, Multiple Data) – optimă pentru procesare paralelă
- Performanța GPU: măsurată în TFLOPS (teraflops), afectată de frecvența ceasului, dimensiunea cache-urilor, numărul de SM/CU/Xe cores
- GPU dedicat: memorie GDDR dedicată, bandwidth >1000 GB/s
- GPU integrat (IGP): folosește RAM sistem, bandwidth ~128 GB/s, mai ieftin dar mai lent
- UMA (Unified Memory Architecture): CPU și GPU partajează rama (AMD APU, PS5, Xbox Series)
- Bandwidth-ul memoriei poate fi bottleneck pentru GPU
SURSE: Wikipedia – Graphics processing unit (https://en.wikipedia.org/wiki/Graphics_processing_unit)
STATUS: VERIFICAT

CONCEPT 3: Rolul CPU vs rolul GPU în jocuri/console
INFORMAȚIE VERIFICATĂ:
- CPU gestionează: etapa Application din pipeline-ul grafic (logica jocului, input utilizator, AI, fizică, detecția coliziunilor, animație)
- GPU gestionează: etapele Geometry și Rasterization (transformări geometrice, iluminare, shading, rasterizare)
- CPU-bound în jocuri: FPS limitat de logica jocului/AI/fizică → GPU sub-utilizat; creșterea rezoluției nu reduce FPS semnificativ
- GPU-bound în jocuri: FPS limitat de complexitatea grafică → CPU sub-utilizat; creșterea rezoluției reduce FPS direct
- Echilibrul CPU-GPU = decizie fundamentală de design în arhitectura consolelor
- CPU trimite comenzi de desenare (draw calls) la GPU; prea multe draw calls = CPU-bound
SURSE: Wikipedia – Graphics pipeline, Wikipedia – GPU, Wikipedia – CPU-bound
STATUS: VERIFICAT – corelat din surse multiple

CONCEPT 4: Bottleneck și performanță
INFORMAȚIE VERIFICATĂ:
- Bottleneck = componenta care limitează performanța întregului sistem
- În sisteme moderne, bottleneck-ul se poate schimba rapid între componente
- Este posibil 100% utilizare CPU cu impact minim pe alte componente
- Upgrade CPU nu are întotdeauna efect dramatic – depinde de task
- Factori multiplii: CPU, GPU, memorie, I/O, bus-ul de date
- Performanța maximă a unui sistem GPU = limitată de puterea electrică consumată și disiparea căldurii
- Design-urile GPU sunt scalabile: multiple chipuri pe placă, sau plăci multiple (SLI/CrossFire – acum rar)
SURSE: Wikipedia – CPU-bound, Wikipedia – GPU
STATUS: VERIFICAT

CONCEPT 5: Aplicație în console
INFORMAȚIE VERIFICATĂ:
- Console folosesc GPU-uri AMD customizate:
  • PS4/Xbox One (2013): bazate pe AMD Radeon HD 7850/7790
  • PS5/Xbox Series X (2020): bazate pe AMD RDNA 2
  • Nintendo 64 (1996): primul hardware T&L GPU pe consolă casă (Reality Coprocessor)
  • PlayStation 1 (1994): primul dispozitiv cu termenul "GPU" (proiectat de Toshiba)
- Console moderne folosesc UMA: CPU și GPU partajează aceeași memorie fizică
  → elimină copierea datelor între memorii separate
  → dar introduce competiție pentru bandwidth
- GPU-urile consolelor nu pot fi upgrade-ate → echilibrul CPU-GPU trebuie optimizat la design
- Dezvoltatorii trebuie să optimizeze jocurile pentru a evita bottleneck-urile specifice consolei
- GPGPU pe console: GPU poate fi folosit și pentru calcule non-grafice (fizică, AI, audio processing)
SURSE: Wikipedia – Graphics processing unit
STATUS: VERIFICAT
