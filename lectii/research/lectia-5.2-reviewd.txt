LECȚIA 5.2 – APU (CPU + GPU)
========================================================================
INFORMAȚII VERIFICATE ȘI SINTETIZATE
========================================================================

CONCEPT 1: Definiția și rolul APU-ului
INFORMAȚIE VERIFICATĂ:
- APU (Accelerated Processing Unit) = microprocesor care combină un CPU și un GPU pe un singur die (cip de siliciu)
- Termen specific AMD (proiectul Fusion, început 2006, lansat 2011), accelerat de achiziția ATI Technologies (2006)
- Diferența față de procesoare discrete: CPU și GPU partajează același die, același bus intern, același controller de memorie
- Avantaj principal: comunicare directă CPU↔GPU fără bottleneck de PCIe, latență redusă, cost și consum redus
- Intel are grafică integrată similară (Intel UHD / Iris), dar nu a folosit termenul APU
- APU-ul este componenta centrală (chipul principal) în toate consolele moderne de jocuri
SURSE: Wikipedia – AMD APU (https://en.wikipedia.org/wiki/AMD_APU)
STATUS: VERIFICAT ✓

CONCEPT 2: Integrarea CPU și GPU – evoluția arhitecturii
INFORMAȚIE VERIFICATĂ:
- Prima generație (Llano, 2011): CPU K10 + GPU Radeon HD 6000 pe același die, 32 nm, memoria partiționată (GPU max 512 MB, CPU restul)
- A doua generație (Trinity/Richland, 2012-2013): Piledriver CPU + Radeon HD 7000 GPU, Turbo Core 3.0 bidirectional (redistribuie puterea între CPU și GPU automat)
- A treia generație (Kaveri, 2014): Steamroller CPU + GCN 2nd gen GPU, HSA-enabled → CPU și GPU partajează același spațiu de adrese de memorie (zero-copy)
- Console (2013): PS4 și Xbox One = APU semi-custom cu 8 nuclee Jaguar + GCN GPU pe un singur die, memorie unificată GDDR5 (nu partiționată)
- Era Zen (2017+): Raven Ridge → Picasso → Renoir → Cezanne → Rembrandt → Phoenix → Strix Point
  - Evoluție GPU: Vega (GCN 5th gen) → RDNA 2 → RDNA 3 → RDNA 3.5
  - Evoluție fabricație: 14 nm → 12 nm → 7 nm → 6 nm → 4 nm
- Console gen 9 (2020): PS5 și Xbox Series X|S = APU semi-custom Zen 2 + RDNA 2, 7 nm
- Tendință: integrare din ce în ce mai profundă (NPU adăugat la Phoenix/Strix Point + CPU + GPU + controller memorie pe același die)
SURSE: Wikipedia – AMD APU (https://en.wikipedia.org/wiki/AMD_APU)
STATUS: VERIFICAT ✓

CONCEPT 3: Comunicarea cu memoria – de la partiționare la memorie unificată
INFORMAȚIE VERIFICATĂ:
- Generațiile timpurii (Llano, Bobcat): memoria fizică partiționată – GPU alocă max 512 MB din RAM, CPU folosește restul; controller de memorie arbitrează cereri coerente vs non-coerente
- Kaveri (2014) + PS4: Heterogeneous System Architecture (HSA) – MMU-ul CPU și IOMMU-ul GPU partajează același spațiu de adrese
  - Pointeri trecuți liber CPU↔GPU (zero-copy: nu mai e nevoie de copiere date între memorii separate)
  - Memorie complet coerentă: GPU accesează cache-ul CPU, coerența cache menținută hardware
  - GPU folosește memorie paginabilă direct prin pointeri CPU
- Console: memorie unificată (GDDR5 la PS4, GDDR6 la PS5) – CPU și GPU accesează aceeași memorie fizică direct
  - Avantaj: bandwidth maxim, zero overhead de copiere, simplitate programare
- Evoluție bandwidth memorie APU: DDR3 ~30 GB/s → DDR4 ~47 GB/s → DDR5 ~102 GB/s → DDR5-5600 ~120 GB/s
- Console: PS4 GDDR5 ~176 GB/s bandwidth, PS5 GDDR6 ~448 GB/s bandwidth (mult mai mult decât APU desktop)
- Shared Power Management: CPU și GPU partajează bugetul de putere, prioritate dinamică în funcție de sarcină
SURSE: Wikipedia – AMD APU (https://en.wikipedia.org/wiki/AMD_APU)
STATUS: VERIFICAT ✓

CONCEPT 4: APU în console – design semi-custom
INFORMAȚIE VERIFICATĂ:
- Consolele moderne folosesc APU-uri semi-custom AMD (design personalizat pentru fiecare consolă)
- PS4 / Xbox One (2013): 8 nuclee Jaguar + GCN GPU, 28 nm TSMC
- PS5 / Xbox Series X|S (2020): 8 nuclee Zen 2 + RDNA 2 GPU, 7 nm TSMC
- Avantaje APU în console vs componente separate (PC):
  - Un singur cip = cost fabricație redus, PCB mai simplu, consum mai mic
  - Memorie unificată = nicio penalizare de transfer CPU↔GPU
  - Turbo Core bidirectional: puterea se redistribuie automat (ex: scená cinematică = mai multă putere GPU; AI complexă = mai multă putere CPU)
  - Design termic optimizat: un singur hotspot de răcit vs N componente separate
- Dezavantaj: upgrade individual imposibil (CPU și GPU pe același die, nu se pot schimba separat)
SURSE: Wikipedia – AMD APU (https://en.wikipedia.org/wiki/AMD_APU)
STATUS: VERIFICAT ✓
